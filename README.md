# 공장·창고 공동중개 매물 아카이브 (부동산판)

인천 공장·창고 매매 109건(73필지)과 경기 북부(남양주·양주·의정부) 임대 5건,
합계 **114건**을 한 페이지에서 찾는 공동중개 매물 아카이브입니다.

**라이브:** https://puppy2848-ctrl.github.io/budongsanpan-warehouse/ (GitHub Pages, `main` 브랜치 루트)

## 화면

- **큰 검색창** — 지역·평수·가격을 그대로 입력 (예: `서구`, `남양주`, `800평`, `10억`) + `찾기` 버튼
- **큰 기본 버튼** — 전체(114) · 매매(109) · 임대(5) · 인천 · 경기북부 (하나만 선택)
- **상세 조건 더보기** — 부평구·서해구·제물포구·남양주·양주·의정부, 1,000평 이상, 대지 500평 이상,
  도크 완비, 층고 9m 이상, 40ft 진출입, 월세 2,500만 이하 (여러 개 선택 가능)
- **지도(`#map`)** — 인천 73필지 + 경기 북부 5곳을 필지 단위로 묶어 핀 표시. 처음에는 권역 클러스터(예: `73건`)로
  묶여 보이고, 확대하면 개별 필지 핀으로 나뉩니다.
  핀을 누르면 그 자리 매물의 가격·담당 부동산 전화번호·`카카오맵` 바로가기·`상세 보기`가 열립니다.
  지역 버튼을 누르면 그 지역 핀만 남고 지도 범위도 그 지역으로 맞춰집니다.
- **매물 카드** — 매매는 `매매가`, 임대는 `보증금/월세`. 카드마다 담당 부동산 번호로 바로 거는
  `전화` 버튼과 `카카오맵` 버튼. 인천 매매 카드에는 용도지역·지목·전력·진입로 폭·인근 IC 등
  실무 스펙 항목을 모달에서 `확인필요`로 표시합니다.
- **공동중개 동선** — 상단·하단에 `공동중개 문의(카톡)` · `공동중개 전화` · `문자 접수` ·
  `내 매물 올리기 · 찾는 매물 의뢰`(구글폼: `docs.google.com/forms/d/e/1FAIpQLScZuBbn-…/viewform`) 버튼.
  구글폼 주소는 `assets/app.js` 상단 `FORM_URL` 한 곳에서 바꿀 수 있습니다.

## 파일

- `index.html` — 화면
- `assets/` — 스타일·스크립트·사진·웹폰트(Pretendard 자체 호스팅)
  - `assets/vendor/leaflet/` — 지도 라이브러리 1.9.4 (CDN 없이 동작하도록 자체 호스팅)
  - `assets/vendor/markercluster/` — 권역 클러스터 플러그인 1.5.3 (같은 이유로 자체 호스팅)
- `data/listings.js` — 매물 114건 데이터와 고객 의뢰 조건(경기 북부 임대 5건용)

## 데이터

- 인천 109건: 네이버페이 부동산 공개 매물(2026-11-26 조회) → 지번(PNU)·카카오 좌표 확인.
  같은 필지에 여러 중개사무소가 올린 매물은 각각 한 건으로 두고 `같은 필지 N건`으로 표시합니다.
- 구글 시트 `부동산판_공장창고_통합매물장_2026`(`인천_매매_109건` / `경기북부_임대_5건` 탭)과
  같은 열 구조입니다. 시트를 CSV로 웹 게시하고 `assets/app.js`의 `SHEET_CSV_URL`에 주소를 넣으면
  시트 내용이 우선 적용됩니다(열 이름 규칙은 `data/listings.js` 상단 주석).

## 지도

- 지도 타일은 OpenStreetMap(무료, 키 없음)입니다. 라이브러리는 자체 호스팅이라 CDN이 막혀 있어도 뜨고,
  타일까지 막히면 주소·금액 목록으로 자동 대체됩니다.
- 위치·길찾기는 전부 공식 카카오맵 링크(`https://map.kakao.com/link/map/<이름>,<위도>,<경도>`,
  `.../link/to/...`)로 연결합니다.
