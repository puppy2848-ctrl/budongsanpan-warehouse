# 부동산판 공장·창고 매물장

경기 북부(남양주·양주·의정부)·인천 권역 대형 공장·창고 매물 아카이브.

**라이브:** https://puppy2848-ctrl.github.io/budongsanpan-warehouse/ (GitHub Pages, `main` 브랜치 루트)
의뢰 조건 8개 대비 판정, 지역·평수·층고·도크·금액 검색, 지도 위치 보기, 상세 모달과 현장 확인 체크리스트를 제공합니다.

- `index.html` — 화면
- `assets/` — 스타일·스크립트·사진·웹폰트(Pretendard 자체 호스팅)
  - `assets/vendor/leaflet/` — 지도 라이브러리 1.9.4 (CDN 없이 동작하도록 자체 호스팅)
- `data/listings.js` — 매물 데이터와 고객 의뢰 조건 (여기만 고치면 화면에 반영)

## 지도

- 목록 위 `#map` 섹션에 매물 5건의 위치를 핀으로 표시합니다. 핀을 누르면 보증금·월세 요약 팝업과
  `카카오맵` · `상세 보기` 버튼이 열립니다.
- 지도 타일은 OpenStreetMap(무료, 키 없음)입니다. 라이브러리는 자체 호스팅이라 CDN이 막혀 있어도 뜨고,
  타일까지 막히면 주소·금액 목록으로 자동 대체됩니다.
- 매물별 카카오맵 링크는 `data/listings.js`의 `lat` · `lng` 좌표로
  `https://map.kakao.com/link/map/<이름>,<위도>,<경도>` (핀) 와 `.../link/to/...` (길찾기) 형식으로 만듭니다.
  좌표만 채우면 지도 핀·버튼이 자동으로 생깁니다.

운영: 부동산판공인중개사사무소 (인천 부평구 열우물로 90)
